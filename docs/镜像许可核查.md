# 镜像许可与 SDK 隔离

源码发行、使用方私有构建和预构建镜像公开发行分别验收。源码的 Apache-2.0 许可不会重新授权 SDK、
第三方二进制或镜像依赖。`python3 jenkins/check_license_inventory.py --scope image` 继续拒绝发行，
直至实际镜像的全层 SBOM、许可/NOTICE、来源和适用的对应源码义务完成独立核查。

## 默认基础镜像

Android Agent [Dockerfile](../jenkins/remote/android-agent/Dockerfile) 的默认最终目标是 `sdk-free`，
仅继承 `runtime`。SDK、NDK 的下载/安装仅出现在独立 `private-sdk` 阶段；DWS 已从全部目标移除；默认目标不继承或复制其层。
必须使用 BuildKit/buildx；第一条 RUN 需要 BuildKit，旧构建器会失败，避免自动执行未选择的私有阶段。
构建说明中出现 SDK 路径或私有阶段，不代表默认生成镜像包含这些文件。

```bash
# 只构建本地候选，不能凭此命令批准镜像公开发行
# architecture 按管理员工具链锁选择；当前官方 Harmony CLT 仅验收 Linux amd64
python3 toolchains.py check
docker buildx build --load --platform linux/amd64 \
  --target sdk-free --tag mobile-ci/android-runtime:local-review \
  jenkins/remote/android-agent
```

默认构建不下载或接受 SDK 许可，不安装 DWS。管理员须从官方来源安装锁定版本 SDK，
自行接受适用协议，并验证包摘要与工具版本。使用现有 [部署清单](部署.md) 的 `sdks.android` / `sdks.harmony`
生成只读挂载：私有 `stateRoot/sdks/android` 和 `stateRoot/sdks/harmony` 是宿主来源，
不能让候选 PR 改写这些目录。PR 节点不挂签名、交付凭据或 DWS 认证状态。
部署消费管理员登记的精确 image ID，`stack.sh start` 不重建镜像。

当前上传/失败通知使用 Python Webhook，不依赖 DWS；Wiki 同步使用 Gitee Git。
当前仓库不安装、认证或预检 DWS，也不再将其状态纳入新迁移备份。旧备份仍校验摘要，旧 DWS 归档保留原件但不自动恢复。
[鸿蒙公开基础](鸿蒙环境重建.md) 同样不包含华为 SDK，官方 CLT 由管理员离线校验并只读挂载。

历史 `jenkins/remote/compose.yaml` 显式选择 `private-sdk` 保留旧私有构建方式；
Harmony 兼容 overlay 覆盖为 `unified-runtime`，基础镜像须由管理员审核。
这些历史入口不是公开发行镜像流程，不在本轮替换生产部署。

## 旧镜像记录与本轮补证

冻结的旧实例曾有 115 条 UNKNOWN；它们按镜像计数，不是 115 个独立软件包。

| 原记录 | 组成 | 本轮处理 |
| --- | --- | --- |
| Android 110 条 | 55 个 JAR，两个镜像各一份 | 全部匹配 Google 官方精确包；补齐此前漏存的大 NOTICE。整 JAR 许可/源码范围仍未证实；默认镜像不纳入这些 payload |
| DWS 2 条 | 同一内嵌 AEM 模块，两个镜像各一份 | 已绑定精确官方发行、固定源码快照；仍缺该模块再分发许可。默认镜像不纳入 DWS |
| XML 3 条 | 两份 shaded isorelax 和一份 RELAX NG Datatype | 官方固定源码、整份发行字节和整组件 MIT/BSD 声明已独立复核，3 条许可声明缺口已关闭 |

累计台账保留原 190 条记录：本轮 3 条取得整组件许可声明，声明已确认总数从 55 增至 58；
20 条仍为纯元数据，112 条仍 UNKNOWN。此计数不表示整体 NOTICE/对应源码义务全部完成。

排除 SDK/DWS 是新镜像的发行范围选择，不是把旧记录改成已获许可，也不是删除旧镜像层中的文件。
旧证据、精确来源、完整 NOTICE 和源码归档由管理员私有保存，不随仓库提交。
Google SDK 协议 [3.4/3.5](https://developer.android.com/studio/terms) 限制整包再分发，
开源组件另按其自身许可处理；官方安装或下载成功不自动建立整包分发权。

## 发行验收

对候选最终 image ID 重扫所有层，确认不含 SDK/NDK、DWS、华为 CLT、签名材料、私有 profile、
运行缓存或凭据。不能先把这些材料放入层，再通过后续 RUN 删除来声称不随镜像分发。
对基础镜像、JDK、Groovy、系统包及所有实际嵌套依赖分别核对精确许可与完整来源，
保留必要 NOTICE 和适用的对应源码。SDK/DWS 不在候选镜像中，只消除这些 payload 的发行依赖；
系统包和 Controller 的发行义务仍须独立验收。未知项、来源未证实或义务未履行继续阻断。

先通过无交付工具预检和负向测试；最后才单独决定是否发布镜像。本轮不推镜像、
不替换生产 Jenkins、不上传安装包、不发送业务通知。
